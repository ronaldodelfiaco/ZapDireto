# 📱 ZapDireto

**ZapDireto** is a web application designed to make it easy to send messages via WhatsApp without saving the phone number to your contacts.

With a simple, fast, and intuitive interface, users just enter the phone number (including area code), confirm it, and are automatically redirected to WhatsApp to start the conversation.

---

## 🚀 Features

- ✅ Send messages without saving the contact
- ✅ Automatic redirection to WhatsApp
- ✅ Clean and straightforward interface
- ✅ 100% web-based (no installation required)
- ✅ Lightweight and responsive

---

## 🎯 Ideal For

- Companies that need to contact customers quickly  
- Freelancers and independent professionals  
- Sales teams  
- Customer support teams  
- Anyone looking for a faster way to start conversations  

---

## 🛠️ Technologies Used

- HTML5  
- JavaScript  
- SCSS  

---

## 🌐 How It Works

1. The user enters the phone number with area code.
2. The system validates the provided number.
3. The application redirects automatically using the official WhatsApp link (`https://wa.me/`).
4. The conversation starts instantly.

---

## 📌 Purpose

To eliminate the need to save temporary contacts just to send a message, improving productivity and saving time in everyday communication.
